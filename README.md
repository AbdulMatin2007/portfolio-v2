# پورتفولیو عبدالمتین توکلی (نسخه چندصفحه‌ای + CMS)

React + Vite + React Router. دارک/لایت، فارسی/انگلیسی (RTL). محتوا (پروژه‌ها و مقاله‌ها) از پنل `/admin` مدیریت می‌شود.

## اجرا
    npm install
    npm run dev        (لینکی که چاپ می‌شود را باز کن)
    npm run build      (ساخت نسخه نهایی)

بدون هیچ تنظیمی هم سایت کار می‌کند (محتوای پیش‌فرض از `src/data/seed.js` نشان داده می‌شود). برای فعال شدن پنل ادمین، Supabase را وصل کن.

## فعال‌کردن CMS (Supabase، رایگان) - یک بار
1. در https://supabase.com حساب بساز و یک Project جدید بساز.
2. از منوی چپ: **SQL Editor > New query**. کل فایل `supabase.sql` را کپی و **Run** کن (جدول‌ها، دسترسی‌ها، پوشه عکس‌ها و ۳ پروژه تو ساخته می‌شود).
3. **Authentication > Users > Add user**: ایمیل و رمز خودت را بساز (تیک Auto Confirm را بزن). این همان ورود ادمین است.
4. **Authentication > Sign In / Providers**: ثبت‌نام عمومی (Allow new users to sign up) را خاموش کن تا کس دیگری حساب نسازد.
5. **Project Settings > API**: مقدارهای `Project URL` و `anon public key` را بردار.
6. محلی: فایل `.env.example` را کپی کن به `.env` و دو مقدار را پر کن. روی Vercel: **Settings > Environment Variables** و دو متغیر `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` را اضافه کن، بعد **Redeploy**.
7. برو به `/admin` (لینک کوچک Admin پایین سایت)، وارد شو، و مقاله یا پروژه اضافه/ویرایش/حذف کن. بدون دیپلوی دوباره، فوراً روی سایت می‌آید.

کلید anon عمومی است و مشکلی ندارد؛ امنیت را همان قوانین دیتابیس (RLS داخل `supabase.sql`) تأمین می‌کنند: همه می‌توانند بخوانند، فقط کاربر واردشده می‌تواند تغییر بدهد.

## فرم تماس (ارسال واقعی)
1. در https://web3forms.com ایمیلت را بده و Access Key بگیر.
2. در `.env` و روی Vercel متغیر `VITE_WEB3FORMS_KEY` را بگذار.
بدون کلید، فرم می‌گوید «متصل نیست» و موفقیت الکی نشان نمی‌دهد.

## تغییر متن‌ها
- متن‌های ثابت سایت (فارسی/انگلیسی): `src/text.js`
- مهارت‌ها و سطحشان (۱ یادگیری، ۲ راحت، ۳ مسلط)، اطلاعات تماس: `src/data/seed.js`
